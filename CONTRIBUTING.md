# Contributing

## Getting Started

1. Clone this repository
2. Create a feature branch from the default branch
3. Make your changes following the patterns in the existing codebase

## Pull Request Process

1. Create a branch: `git checkout -b feature/your-change`
2. Commit using [Conventional Commits](https://www.conventionalcommits.org/): `feat:`, `fix:`, `chore:`, `docs:`
3. Push and open a Pull Request against the default branch
4. Ensure CI checks pass
5. Request review from the team listed in CODEOWNERS

## Code Standards

- Follow the existing code style and patterns in the repository
- Keep changes focused and minimal
- Update documentation if behavior changes

## Reporting Issues

Open an issue describing the bug or feature request with steps to reproduce.
